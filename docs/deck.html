On a big or hard job, one agent fails in four ways

WhyHowWhat

Google's answer: split the work, and have other agents check it

Google's Antigravity ships this as /goal, /boost, /swarm and /teamwork. Google reports results like a video decoder rewritten in Rust that ended up 20–30% faster than the C++ original.

The catch: Google bans driving Antigravity from Claude Code, and has disabled accounts for it. So we copy the ideas into Claude Code instead.
WhyHowWhat

Each problem has a fix, and each fix has a tool

Agent teams solve something else: several sessions working in parallel, which you can redirect mid-task.
